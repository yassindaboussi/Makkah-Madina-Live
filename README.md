## 🎯 Overview

A beautifully designed web platform providing **24/7 live streams** of the two most sacred sites in Islam:

- 🕋 **Masjid al-Haram** (Makkah) - The Grand Mosque
- 🕌 **Masjid an-Nabawi** (Madina) - The Prophet's Mosque

Watch the spiritual journey unfold in real-time from your device, anytime, anywhere.

**Live at:** https://makkahlive.netlify.app/

## 🚀 Quick Start

### View Live

1. **Visit the site:** https://makkahlive.netlify.app/
2. **Choose a mosque:**
   - Click on "Makkah" for Al-Haram Mosque stream
   - Click on "Madina" for Prophet's Mosque stream
3. **Enjoy the live stream** - Streams play automatically

### Run Locally

```bash
# Clone the repository
git clone https://github.com/yassindaboussi/Makkah-Madina-Live.git
cd Makkah-Madina-Live

# Open in browser
open index.html
# or simply drag index.html into your browser
```
